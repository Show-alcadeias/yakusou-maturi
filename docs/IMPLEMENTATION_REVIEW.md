# 実装レビュー

この文書はMVP（Ver.0.1）完了時点の記録。後付けメディアの変更と検証は [MEDIA_EXTENSION_REVIEW.md](MEDIA_EXTENSION_REVIEW.md) を参照。

## 総合判定
Think → Plan → Build → Test → Review の順でMVPを完了。最初のローカルコミットは設計文書のみで、制作前自己レビュー後にコードを作成した。GitHubでも設計コミットと実装コミットを分ける。mainは空リポジトリの比較元となる案内READMEだけとし、成果を自動マージしない。

11イベント、3探索先、レオの救出・帰還、履歴による条件付き本文・応答、薬草評価と救出経過を組み合わせる結末、1枠の再開を実装。初稿のキャラクター設定は正本に沿い、レオは鑑別・応急調合の専門性を示す。ムハンマドの人物背景は追加していない。

## 検証で修正した点
- RichTextLabelの `add_text` / `clear` と `text` プロパティを混在させると、本文蓄積・イベント切替時の扱いが不整合になった。`text` の更新に統一し、前イベントの本文が残らない回帰チェックを追加。
- 可変フォントの既定ウェイトは100だったため、FontVariationで400を明示。日本語の読みやすさを改善。
- ヘッダーのタイトルボタンは折り返し時の最小幅を明示し、縦に細くつぶれる問題を修正。
- DMリソースをコードの解析時にpreloadすると、まっさらな初回インポートでインポーター登録前に解決できない場合があった。Flowのready時に読み込む方式へ変更し、`.godot`なしの環境で再確認。
- `--script` の起動時にも使えるよう、DM Autoloadはノード参照で取得。独自の代替実装はしない。

## 依存と抽象化
不要なライブラリ・テストフレームワーク・DIコンテナ・汎用StoryCoreは追加していない。公式DMのエディタ・サンプルファイルは原形を保って同梱するが、ゲームからサンプルUIを起動しない。公式ソースは改変していない。MediaAdapterは通知signalを1段中継するだけで、外部モジュールからの返答を待たない。

日本語フォントは約9.6MBあり、短いMVPに対して大きめ。ただし本文を追加する際の字形不足を避け、サブセット再生成の工程を増やさない利点を優先した。

## 編集・保守性
本文・条件式は `story/story.dialogue` が正本。状態変更は `state.act(action_id)` へ集め、文章からの任意プロパティ代入を避けた。UIはDMが許可した応答を表示するだけで、条件式を再実装しない。

新しいフラグ・行動にはGameStateの操作と保存形式検証、新イベントにはGameFlowのID・遷移・段階検証、テストの追加が必要。これは現規模では明示的で追いやすいが、規模拡大時には編集箇所が増える。巨大な分岐を増やす前に共通イベントへの合流を維持する。

全経路テストは現状734経路で十分速い。独立した選択肢を増やし続けると組み合わせが急増するため、将来は重要経路の固定回帰テストとフラグごとの真偽テストに分割する。Webテストの40入力は現シナリオの既定経路に合わせた値で、台詞を追加した場合は更新が必要。

## 将来の変更範囲
BGM・背景はMediaAdapterの `cue_requested(event_id)` を購読するノードとID別アセット表を追加すればよい。GameStateやDM本文に音声プレイヤー・画像ノードへの参照を入れる必要はない。会話途中の立ち絵変更が必要なら、DMのタグをUIからAdapterへ渡す小さな拡張をその時点で行う。

ダイス・戦闘はGameFlowのイベント境界に接続し、結果をGameStateへ記録して会話条件から読む。アイテム管理は薬草の数・品質の問い合わせを維持したまま外部モジュールへ委譲できる。今回これらの未使用インターフェースは実装していない。

## 残る技術的負債・範囲外
- シナリオは生成初稿。作者の文章校正・テンポ調整は未完了。
- セーブは形式番号1のみ。将来の状態追加は移行処理か旧データ拒否方針の更新が必要。本文途中の厳密な復元・複数枠なし。
- 保存の妥当性チェックは破損・不整合対策であり、外部編集の防止機構ではない。
- 現在のUIは固定の論理解像度を縮小表示する。640×480で操作可能だが、さらに小さい画面の専用レイアウト・文字サイズ設定はない。
- スクリーンリーダー、ゲームパッド、モバイル向け操作設計は未検証。
- Godot/DMのバージョン更新は未検証。固定版のコンパイラと全経路テストを通して更新すること。
- 音声出力・実メディア・将来モジュールは未実装。ゲームの現在の進行には影響しない。
- ゲーム固有コードと文章の配布ライセンスは作者判断待ち。第三者ライセンスは同梱・出典記録済み。
