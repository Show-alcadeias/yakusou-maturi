## 意図的に変更しなかった部分
- **prologue / approach**：祭り・依頼・何となく受ける動機は既に明確。家族の悲嘆、主人公の信条、英雄的な動機を足していない。
- **meadow / ridge**：採取と調査の対比が具体的。「模範的な植物」「結び方だけ予習」は場面に固有の冗談として残した。
- **aid**：3救助手順は状態と一致しており、レオの調合が実際に救助へ寄与する。「植物学的すぎた」も含め全文維持。
- **descent**：「帰りは一人増える。荷物としては十分だ」、選別によるレオの専門性、下りでも足元を見る描写を維持。
- **発見・結末の成立している差分**：近道、救出速度、ロープ・錬金術・肩を貸す救助の結末、次の祭りへの締めを維持。
- **結末名3種類**：新しい名称や順位付けを加えていない。excellentも優勝を意味する判定にはしていない。

「手ぶら」の比喩など、語義の幅はあるが文脈で読める表現を、好みだけで説明調に統一しなかった。長文・短文・冗談を均等に配分することも目標にしなかった。
