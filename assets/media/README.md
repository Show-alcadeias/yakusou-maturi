# Ver.0.2の仮素材

すべて今回の開発作業で独自作成。外部の画像・楽曲・サンプル音源、画像生成サービス、音楽生成APIは使用していない。

- `town.svg`：街と祭りの旗。手書きの単純なベクター図形。
- `mountain.svg`：山道。手書きの単純なベクター図形。
- `stream.svg`：沢と三つの石。手書きの単純なベクター図形。
- `mountain.wav` / `discovery.wav`：独自に並べた短い旋律と正弦波の合成。各8秒、16kHz、16bit、モノラル。ゲーム内でループする。完成楽曲ではなく接続検証用。

音源の再生成：プロジェクトルートで `python3 tools/generate_media_audio.py`。標準ライブラリのみ。SVGは直接編集できる。IDと実ファイルの対応は `media/catalog.json` に集約。

これらのオリジナル素材の公開ライセンスは、ゲーム本体と同様に作者判断とし、今回新たな包括ライセンスは設定しない。第三者素材の利用条件に依存するものではない。
